## 1. 一句话概括风格

**「照片壁纸 + 半透明磨砂卡片」的浮层式设计**：整屏一张家庭背景图，所有内容以 16–20dp 圆角、无描边、无阴影的半透明卡片浮在壁纸上；浅色模式下卡片变白、深色模式下卡片变近黑，但**顶栏文字永远是白色**（因为它压在壁纸上）。

二级页面（智能 / 我的 / 设置）则切换为**纯色底 + 纯白/纯黑分组卡片**，不再用壁纸。

## 2. 全局视觉语言

### 2.1 材质与层次

| 层级 | 表现 | 用法 |
|---|---|---|
| 底层 | 家庭背景照片（用户可换）| 首页 / 房间页 / 场景页 |
| 卡片层 | 半透明 + 背景模糊，圆角 16–20dp，**无描边、无阴影** | 设备卡、状态胶囊、按钮 |
| 浮层 | 实色（或高不透明度）+ **大而柔的阴影** | 点按弹出的锚点菜单、设备详情浮窗 |
| 遮罩 | 详情浮窗出现时主界面轻微变暗 | 设备详情 |

关键点：**同级元素靠明度差区分，不靠描边和阴影**；只有"浮起来的窗口"才有阴影。这正是我们桌面端"子窗口和主窗口糊成一片"的反面教材——米家的做法是主界面变暗 + 子窗口带阴影，层次一眼可辨。

### 2.2 圆角

| 元素 | 圆角 |
|---|---|
| 卡片 / 分组卡 / 弹出面板 | **18 dp**（实测 47–50 px） |
| 状态胶囊、小标签 | **16 dp**（实测 43 px） |
| 大按钮（场景胶囊） | **20 dp**（实测 54 px） |
| 设备详情浮窗 | 18 dp |
| 图标底块（我的页行图标） | 10 dp |
| 滑条轨道 | 高度的一半（纯胶囊） |

> 不是"全圆角胶囊"——即使是 60dp 高的按钮，圆角也只有 20dp。这是米家区别于 iOS 的一个细节。

### 2.3 间距节奏

- 基础单位 **8 dp**，常用步进：8 / 12 / 16 / 24 / 28 / 72
- 卡片内容内边距：**16 dp**（小卡）/ **26 dp**（大卡）
- 卡片之间：**8 dp**（首页网格）/ **12 dp**（智能页网格）

### 2.4 字体层级

| 用途 | 字号 | 字重 |
|---|---|---|
| 家庭名（页面标题） | 24 sp | Medium |
| 分区标题（"手动控制"） | 18 sp | SemiBold |
| 房间标签（激活 / 未激活） | 20 / 16 sp | Medium / Regular |
| 卡片标题、列表行 | 16 sp | Medium |
| 指标大数字 | 28 sp | SemiBold |
| 卡片副标题、列表副行 | 13 sp | Regular |
| 状态胶囊、底部导航 | 12 sp | Regular |
| 指标单位（"温度"） | 11 sp | Regular |

字体是小米自家的 **MiSans**（思源黑体同源，横竖笔画对比小、字腔开）。桌面端可退化为 `Microsoft YaHei UI`，或打包思源黑体 `Source Han Sans SC`。

### 2.5 文字颜色（同一套规则跨主题）

| 场景 | 值 |
|---|---|
| 壁纸上的标题 / 激活标签 | `#FFFFFF` |
| 壁纸上的未激活标签 | `rgba(255,255,255,0.36)` |
| 深色卡片主文字 | `#FFFFFF` |
| 深色卡片次要文字 | `rgba(255,255,255,0.48)` |
| 浅色卡片主文字 | `#000000` |
| 浅色卡片次要文字 | `rgba(0,0,0,0.35)` |
| 深蓝胶囊内文字 | `rgba(255,255,255,0.65)` |

### 2.6 强调色

| 用途 | 色值 |
|---|---|
| 开关 ON / 执行按钮 | `#4CC38A` ~ `#5ECA98`（薄荷绿） |
| 灯光亮度滑条 | `#F3BE44`（琥珀黄） |
| 门锁"已上锁"状态 | `#2F7BFF`（蓝） |
| 警告行 | `#F5A623`（橙三角） |
| 消息红点 | `#FF4D4F` |

设备图标本身保留**实物照片/彩色剪影**（绿色叶片、白色吸顶灯、黑色网关），不统一成单色线性图标——这是"设备可辨识度"优先于"视觉统一"的选择。

## 3. 首页 / 房间页版式（核心）

### 3.1 整体结构（自上而下）

```
┌──────────────────────────────────────────────────────┐
│  系统状态栏                                            │
│                             ○  ▣  ⌾•  ＋   ← 40dp 圆形触摸区，右对齐
│  示例家庭 ▾                              🌙 28°          │ ← 家庭名 24sp + 小三角
│  场景  全屋  书房  卫生间  客厅  厨房  次卧  儿童房      ≡   │ ← 房间标签 + 更多房间
│  ▔▔▔                                                │
│  [28.3-29.5°][62-73%][中][亮灯5][吹风中]            │ ← 状态胶囊 120×56
│  [ ⊕ 客厅全部关灯 ]                                  │ ← 场景快捷胶囊 163×60
│  ┌─────────┬─────────┬───────┐                      │
│  │ 环境(2)  │ 摄像头(2)│ 灯(2) │                      │ ← 卡片行 167dp 高
│  ├────┬────┬────┬────┬────┬──┤                      │
│  │ 1  │ 1  │ 1  │ 1  │ 1  │ 1│                      │
│  └────┴────┴────┴────┴────┴──┘                      │
│              ( 米家 智能 产品 商城 我的 )             │ ← 浮动导航胶囊 620×43
└──────────────────────────────────────────────────────┘
```

### 3.2 关键尺寸

| 元素 | 尺寸 / 位置 |
|---|---|
| 内容左右边距 | **72 dp** |
| 顶栏图标 | 40×40 dp 触摸区，间距 8 dp，右边缘对齐内容区 |
| 家庭名基线 | 距顶部 ~102 dp；左侧 80 dp |
| 房间标签行 | y=153 dp，行高 44 dp，标签间距 **24 dp** |
| 激活下划线 | 宽 = 文字宽，高 2 dp，距文字底部 6 dp |
| 状态胶囊 | 120 × 56 dp，间距 8 dp，圆角 16 dp |
| 场景快捷胶囊 | 163 × 60 dp，圆角 20 dp |
| **卡片网格** | 起点 y=357 dp；**6 列**；列宽 163 dp；行高 167 dp；间距 8 dp |
| 大卡 | 2 列宽 = 334 dp |
| 底部导航容器 | y=700 dp，高 60 dp |
| 导航胶囊 | 620 × 43 dp，水平居中，距屏底 24 dp |

> 换算：1164 − 72×2 = 1020 dp 内容宽；6×163 + 5×8 = 1018 dp ✓

### 3.3 卡片规格

**① 小设备卡（1 列）**
- 56 dp 高的顶部区域放设备实物图/图标；右上角 22 dp 圆形电源按钮（关闭时半透明白，开启时绿底白字）
- 底部：设备名 16 sp（单行，超出省略），下方 13 sp 房间名 `rgba(255,255,255,0.48)`
- 宽度不足时设备名会换行并在第二行末尾"…"（米家做得一般，我们可以用 `ElidedLabel` 更干净）

**② 环境卡（2 列）**
- 左上：36 dp 彩色图标 + 标题 16 sp + 副标题 13 sp（"1 个设备运行中"）
- 底部一行三组指标：数字 28 sp + 单位/标签 11 sp，左对齐、基线对齐

**③ 摄像头卡（2 列）**
- 模糊的实时画面作为背景；左上角文字压一层渐变；右上角「进入 ›」小胶囊；中央播放按钮

**④ 灯卡（2 列，开启时变白）**
- **设备状态驱动卡片配色**：灯亮时整卡变为半透明白（85%），文字转黑
- 右上角 34 dp 绿色圆形开关
- 底部 22 dp 高纯胶囊滑条，颜色取自灯的色温/亮度（实测 `#F3BE44`），白色 16 dp 圆点滑块

**⑤ 场景卡（场景页）**
- 白卡，标题 16 sp + 副标题 13 sp，底部两枚「全开 / 全关」内嵌小按钮（12 dp 圆角，白底 + 浅描边）

## 4. 二级页面

### 4.1 智能（自动化）

- **不用壁纸**：纯色底（深色 `#000` / 浅色 `#FAFAFA`），卡片深色 `#242424` / 白色 `#FFF`
- 顶部：右侧「场景日志」「＋」两个 40 dp 图标；标题仍为家庭名 24 sp
- 标签：`探索` / `我的智能`（16 sp + 下划线），右侧漏斗筛选图标
- **手动控制**：**4 列**卡片，249 × 118 dp，间距 12 dp
  - 卡片内：标题 16 sp → 「本地」小标签（12 sp，描边胶囊）→ 左下 36 dp 圆形设备图标 → 右下绿色胶囊执行按钮
- **自动化**：**2 列**卡片，504 × 105 dp，间距 12 dp
  - 卡片内：标题 16 sp（可换行，最多 2 行）→ 「本地」标签 → 左侧触发/动作图标链（36 dp 圆形 + "⋯" + 多个动作图标）→ 右侧 49×32 dp 开关
- 分区标题 18 sp，上方间距 24 dp

> **这是本项目"电脑-米家自动化"的天然落点**：如果将来做桌面端自动化，直接复用这个"2 列卡片 + 右侧开关 + 图标链"的表达。

### 4.2 我的

- 纯色底（深色下是极暗的蓝黑渐变）
- 内容为**窄栏**：左右边距 **147 dp**（内容宽 ~870 dp），和首页的 72 dp 边距不同
- 顶部：姓名 26 sp +「›」，副标题 13 sp，下面一枚「2 个家庭 | 12 个智能设备」信息胶囊；右侧头像圆 44 dp
- 家庭卡：家庭名 16 sp +「3 个成员」，右侧成员头像 33 dp 叠加 + 「＋」
- 功能列表卡：行高 62 dp，行内 36 dp 圆角彩色方块图标（每行不同色相）+ 16 sp 标签 + 右侧「›」，部分行右侧带值（"良好"）

### 4.3 设置（更多设置）

- 单列长列表，分节：通用 / 隐私与安全 / 关于
- 内容边距 ~147 dp（与"我的"一致），分组卡片 18 dp 圆角
- **行高 56 dp**，行文字 16 sp；副说明 13 sp
- 右侧三种样式：`›` / `值 + ›` / **44 × 24 dp 开关**
- 页面顶部标题居中 16 sp，左上返回箭头（54 dp 触摸区）
- **退出登录**：页面最底部，**居中胶囊按钮**（~460 × 44 dp，深灰底、白字，不是红色），与上方分组留 ~48 dp 间距

> 结论：米家**没有**"账号切换 / 多账号同时登录"，只有"我的 → 更多设置 → 退出登录"。我们若做多账号，属于超出原版的能力。

## 5. 浮层组件

### 5.1 锚点菜单（"更多房间" / "＋"）

- 从触发图标下方展开，右边缘对齐触发图标
- **280 dp 宽**，行高 **55 dp**，内边距 28 dp，圆角 18 dp
- 无分隔线；行右侧可放灰色计数（"17""21"）
- 底部可再挂一行带图标的操作项（"导航编辑""全部设备"）
- 深色下底色 `#2C2C2E`，浅色下纯白

### 5.2 设备详情浮窗

- **不是全屏页，是一个居中的浮窗**：502 × 644 dp，18 dp 圆角，大阴影，主界面轻微变暗
- 标题栏 40 dp 高：左「←」/ 中间品牌 logo + 设备名 16 sp / 右「⋮」
- 内容分组卡：18 dp 圆角，卡间距 16 dp，卡内边距 24 dp
- 深色下窗口底是该设备的主题色压暗版（例如灯是 `#0D0B1B`），行卡 `#242424`
- 控件：
  - 开关行：40 dp 圆形渐变按钮 + 16 sp 标签
  - **滑条是"整条轨道即控件"**：40 dp 高、纯胶囊、无独立滑块；轨道内嵌图标（左"小灯泡"、右"大灯泡"），左侧填充色渐变到右侧深灰；拖动任意位置都可调

> 这条对我们是直接可用的：**设备详情做成带阴影的浮窗 + 主窗口降暗**，正好解决当前的层次问题。

## 7. 落到本项目（桌面端）的取舍建议

| 米家的做法 | 桌面端是否照搬 | 建议 |
|---|---|---|
| 照片壁纸做底 | 部分 | 支持"纯色 / 渐变 / 自选图片"三选一，默认纯色；图片模式自动降饱和 + 模糊，避免干扰卡片可读性 |
| 卡片半透明磨砂 | 是 | Qt 无实时 backdrop blur，用"预先模糊的背景图切片 + 半透明填充"来仿；纯色模式直接给不透明卡片 |
| 16/18/20 dp 三档圆角 | 是 | 直接写进 `theme.py` 的圆角 token |
| 6 列网格 + 1/2 单位卡 | 是 | 现在设备卡是固定列宽，可改为按 6 列栅格计算，随窗口宽度自适应 |
| 卡片无描边无阴影 | 是 | 去掉当前卡片描边，靠背景明度差；只在 hover 时加 1dp 提亮 |
| 浮窗带阴影 + 主窗降暗 | 是 | 优先级高，直接解决"糊成一片" |
| 顶栏家庭名 24 sp + 小三角 + 房间 20/16 sp 下划线 | 是 | 与现有 `home_tabs.py` 对齐字号、下划线（宽=文字宽、2dp 高、6dp 间距） |
| 房间标题行放"全开/全关" | 否 | 米家没有这一行（它把「全开/全关」放在场景页的房间卡里），我们自己加过两枚小胶囊，又在 2026-11-06 删掉了——桌面端一个房间的品类太杂，一刀切风险大于收益；一键控制交给场景栏 |
| 「隐藏设备」房间 | 否 | 米家无此概念，保持自定，但用同样的房间标题样式 |
| 底部浮动导航胶囊 | 可选 | 桌面端更适合左侧栏或顶部页签；若做"页面切换胶囊"，照 620×43、距底 24dp |
| 详情页大号胶囊滑条 | 是 | 视觉收益大；实现上可用无 thumb + 自绘轨道的 `QSlider` |
| 开关 44×24（设置）/ 49×32（列表） | 是 | 现有 `ToggleSwitch` 42×24 调整为 44×24，新增 49×32 变体 |
| 退出登录 = 底部居中灰胶囊 | 是 | 比红色危险按钮更克制，符合原版 |
| 设置 = 单列分节长列表 | 是 | 我们现在的四页签可保留，但页内容改成"分节 + 行高 56 + 右侧值/箭头/开关" |
