# MiHomePanel v0.1.7

这个版本加了**桌面挂件**：一块常驻桌面的紧凑面板，把常用的几台设备摆在桌面上，不用先
打开主窗口。解压后双击 `MiHomePanel.exe` 即可使用，压缩包仍自带打过补丁的 go2rtc
（首帧约 2 秒）。

## 本次更新

### 桌面挂件（新）

- **三档层级**：默认「普通」（和普通窗口一样，点一下浮到最前）；「贴桌面」按 Win+D 后
  仍在、不挡任何窗口；「置顶」压在最前。头部图层按钮随时切换，位置不会丢。
- **宫格摆设备**：行 × 列都可选 1–6（最多 6×6）。拖到哪格就放哪格，**空着的格子会原样
  留空**，后面的设备不会挤上来。
- **管理窗**：点头部齿轮打开。空格中间「＋ 添加设备」，选择器是「家庭 → 房间 → 设备」
  三层树——挂件跨家庭，别的家的设备也能摆进来。两格之间拖动即交换，格子右上角 × 移除。
- **卡片**：158×56 紧凑卡，名称 + 房间 / 状态。点电源直接开关，点空白进设备详情，
  离线整卡压暗。开关图标与主界面卡片同一套字形。
- **底部状态行**：左边「N 台设备 · M 台离线」，右边耗材提醒——「耗材」后面跟两枚圆点，
  灰的是轻提醒、红的是重提醒，只显示有数的。
- **入口**：左栏分隔线下方的「桌面挂件」，点一下出现、再点收起；启用时标签右侧有一个
  主题色圆点，和「切换页面」的按钮区分开。设置 → 常规 → 启动设置里另有「启动时开启
  桌面挂件」，管的是下次启动要不要自动出现。
- 头部四个按钮（打开主窗口 / 层级 / 管理 / 收起）都有悬停提示；齿轮和图层不再藏在
  「…」菜单里。
- 贴桌面档在 explorer 重启后会自己重建并贴回桌面（0.1 秒级判死、1 秒级重建），
  不用重开程序。

### 修正

- **修「用了挂件之后主界面点不动」**：挂件早先是主窗口的子控件，带 `Qt.Tool` 的子控件
  一旦建原生窗口，Qt 会把主窗口里同级的描边层、缩放边、内容层全部改成原生窗口，铺满
  整窗的 1px 描边层就把所有鼠标事件截走了。改成独立顶层窗口后恢复正常。
- **修挂件挂上桌面后看不见**：挂进桌面图标层时窗口的 `WS_VISIBLE` 会被清掉，补了
  `SWP_SHOWWINDOW`。
- 挂件底板与主窗口背景同源（跟主题的渐变/纯色一致），卡片不再自带一圈描边，深浅色下
  的层次都跟主界面一致。

## 安装

1. 解压整个目录（不要只拷 exe，`_internal\` 和 `go2rtc\` 都要保留）。
2. 双击 `MiHomePanel.exe`。
3. 首次启动会弹出二维码，用米家 App 扫码登录；凭据只保存在本机。

从 0.1.6 升级可以直接覆盖程序目录，设置与登录态都在 `%LOCALAPPDATA%\MiHomePanel\`
下，不受影响。

系统要求：Windows 10 / 11 x64。

## 已知限制

- 挂件只做了三档窗口、宫格槽位与设备管理；**折叠状态条、背景色 / 锁定、多屏夹回还没做**。
- 挂件的跨家庭能力只体现在「选设备」这一步：挂件本身不区分家庭，家庭切换不影响它。
- 用别的工具强杀 `explorer.exe` 且系统没开自动重启 shell 时，桌面要手动拉起来；挂件会在
  shell 回来后自己贴回去，但期间桌面上看不到它。
- 目前同一时间只支持一个米家账号。
- 摄像头只做实时画面、声音和云台方向；画质切换、回放、云存储不在计划内。
- 耗材页只收数值型属性（百分比、剩余量这类）；枚举、布尔、文本属性没有"阈值"可套，
  不提供。
- 未适配的品类会走通用兜底，控件能出，但文案可能仍是云端英文。
- 全局快捷键**跨家庭也唯一**：家庭 A 和家庭 B 不能各用一个 `Ctrl+1`。
- "本程序启动时"只在**登录且设备列表加载成功**后触发；未登录时那条规则会等到下次启动。
- 图标用的是单纯的显示器 + 房子造型，与米家官方图标无关。
