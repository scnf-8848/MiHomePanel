# MiHomePanel v0.1.6

这个版本把左侧功能区空着的两个入口填上了：**「耗材」和「监控」现在都是完整页面**，
不再是占位。解压后双击 `MiHomePanel.exe` 即可使用，压缩包仍自带打过补丁的 go2rtc
（首帧约 2 秒）。

## 本次更新

### 耗材页（新）

- **手动挑要盯什么**：一条监控项 = 一台设备的某个数值属性 + 两档阈值。属性由你自己选，
  程序不猜——所以不会冒出"铃声类型只剩 30%"这种莫名其妙的提醒。
- **两档提醒**：轻提醒（橙）/ 重提醒（红），余量降到阈值（含等于）时卡片变色，侧栏
  「耗材」旁边同步出圆点计数（轻重不同色）。留空或填 0 = 不启用那一档。
- **三种卡片样式**，整页统一切换（右上角下拉）：横条、整卡染色、圆环。
- **按家庭分开**：每条监控项归属添加时的家庭，切家庭只显示当前家庭的。
- 卡片可以拖动排序（「排序」下拉里选自定义时才开放）；离线设备的读数右下角标出更新时间，
  超过一天不算"新鲜"。

### 监控页（新）

- **五种预设布局**：单窗口 / 左右两分 / 四宫格 / 一大两小 / 一大五小（左上 2×2 主窗 +
  周围 5 格）。右上角下拉切换，格子里正在看的画面会跟着搬过去，**不重新取流**。
- **左侧选源栏**：每台摄像头一张卡（用的是它最后一帧的模糊图，重启程序也还在），
  拖到右边某个格子就换那一路；单击则放进第一个空格。摄像头多了可以上下滚动。
- **进页面不自动播**：格子里显示上次那一帧的模糊封面 + 播放键，点了才建立连接——一进
  监控页就几路齐解，风扇会先响起来。地址会提前预热，点播放比原来快一截（约 3 秒 → 2 秒）。
- 同一个格子双击放大；右上「全部停止」一次停掉所有画面；最多同时 6 路。
- 同一台设备在详情页 / 独立窗口打开时，只会腾出监控页那一格，其余继续播。

### 其它

- 摄像头「取流方式（局域网 / 远程）」从「外观」设置挪到新的「设备」页，跟设备相关的
  开关放一起。
- 卡片副标题没内容时不再画一个孤零零的破折号；确认框按钮高度固定，不再被字体行高撑成方块。

## 安装

1. 解压整个目录（不要只拷 exe，`_internal\` 和 `go2rtc\` 都要保留）。
2. 双击 `MiHomePanel.exe`。
3. 首次启动会弹出二维码，用米家 App 扫码登录；凭据只保存在本机。

系统要求：Windows 10 / 11 x64。

## 已知限制

- **监控页的多路效果没被完整验证过**：作者手上的摄像头数量比「一大五小」的格数少，
  六格满配、6 路并发时的 CPU 与首次全亮时长、异地多路都没有实测数据。代码路径与上限
  有单元验证，真机手感请以你自己的设备为准。
- 目前同一时间只支持一个米家账号。
- 摄像头只做实时画面、声音和云台方向；画质切换、回放、云存储不在计划内。
- 耗材页只收数值型属性（百分比、剩余量这类）；枚举、布尔、文本属性没有"阈值"可套，
  不提供。
- 未适配的品类会走通用兜底，控件能出，但文案可能仍是云端英文。
- 全局快捷键**跨家庭也唯一**：家庭 A 和家庭 B 不能各用一个 `Ctrl+1`。热键是操作系统级的，
  不分家庭。
- "本程序启动时"只在**登录且设备列表加载成功**后触发；未登录时那条规则会等到下次启动。
- 图标用的是单纯的显示器 + 房子造型，与米家官方图标无关。
