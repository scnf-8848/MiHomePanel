# MiHomePanel v0.1.1

一次以「本机数据可控」为主的维护版：设备配置可以单独重置，能力缓存会自己纠正历史误判，
文档也按「用 / 改 / 查 / 历史」重新分了一次。解压后双击 `MiHomePanel.exe` 即可使用，
安装包仍自带打过补丁的 go2rtc。

## 本次更新

- **设备右键新增「强制刷新」**：清掉这台设备「已确认不支持」的历史记录，并立刻重查它
  全部可读属性。固件升级后某个功能一直不出现时用它；**它清的不是读数**，日常数据本来
  就在自动轮询。不弹确认，也不改任何本地配置。
- **设备右键新增「重置设备配置」**：一次清掉能力缓存、卡片样式、隐藏状态和房间内排序，
  让这台设备回到默认样子。会先弹确认并逐项列出将清除的内容；被隐藏的设备重置后会
  **重新出现在卡片墙原位置**。不影响米家 App 里的设备、场景与自动化，也不影响登录。
- **设置页新增「全部重置」**：入口在「设置 → 账号 → 设备配置」，按与单设备重置相同的
  口径清所有设备，确认窗会给出受影响设备数、卡片样式 / 隐藏 / 排序 / 能力缓存各多少条。
- **能力缓存自愈**：启动时按当前错误码规则重新校验历史记录，把「设备离线」「暂时性
  错误」这类当初误记成"不支持"的条目自动丢掉。换过型号或升级过固件的设备，也会在
  规格变化时自动重新学习，不需要再手动删缓存。
- **文档重组**：新增文档总索引，按「我要用 / 我要改代码 / 我要查结论 / 我要看历史」
  四条路径分流；开发文档拆成架构、UI、自动化、摄像头、数据轮询、打包发布、测试验证
  七篇专题，`TODO.md` 只保留当前待办与已作废结论，完成记录移入历史归档。

## 安装

1. 解压整个目录（不要只拷 exe，旁边的依赖目录和 `go2rtc/` 都要保留）。
2. 双击 `MiHomePanel.exe`。
3. 首次启动会弹出二维码，用米家 App 扫码登录；凭据只保存在本机。

系统要求：Windows 10 / 11 x64。

## 已知限制

- 「耗材」「监控」两个入口仍是占位，页面还在规划。
- 目前同一时间只支持一个米家账号。
- 摄像头只做实时画面、声音和云台方向；画质切换、回放、云存储不在计划内。
- 未适配的品类会走通用兜底，控件能出，但文案可能仍是云端英文。
- `MiHomePanel.exe` 右键「属性 → 详细信息」里没有版本号；程序内标题与「关于」页是准确的。
