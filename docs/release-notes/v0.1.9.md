# MiHomePanel v0.1.9

这个版本的主题是**把该看见的信息放到看得见的地方**：顶栏多了全屋温湿度和一颗消息入口，
耗材页不再只管当前家庭，托盘里也能直接开关桌面挂件。同时撤掉了两样东西——顶栏搜索框，
和详情页左下角那块反复试过都不合适的位置。

解压后双击 `MiHomePanel.exe` 即可使用，压缩包仍自带打过补丁的 go2rtc（首帧约 2 秒）。

## 本次更新

### 新增

- **顶栏全屋温湿度**：设备计数右边多两颗胶囊，显示当前家庭所有温湿度读数的**范围**
  （`21.5-22.8°C`、`46-51%`），不是平均值——平均值会把"有一间 32 °C"这个最该被看见的
  事实抹掉。鼠标停上去逐台列出（一台一行）。只看品类自己声明的读数（温湿度计、空调室温、
  净化器、浴霸等）；离线、别的家庭、数值离谱的一律不参与，一台都没有就整块不显示。
  设置 → 外观 → 顶栏展示里可以分别关掉在线设备 / 温度 / 湿度三颗。
- **消息中心**：顶栏温湿度右边一颗铃铛胶囊，**鼠标停上去浮出**最近的通知（设备完成任务、
  滤芯到期、场景通知），移开 260 ms 收起，Esc 也能关。只显示**当前家庭**的记录。
  只读：不标已读、不删除；也不显示"未读条数"——这里从不标已读，那个数只会永远是全部未读。
- **托盘菜单「桌面挂件」**：右键托盘图标可以勾选显示 / 隐藏挂件，只影响这一次，不改
  「启动时开启桌面挂件」的设置。挂件自己关掉、或看门狗重建它，勾选状态都会跟着变。

### 改进

- **耗材页改成跨家庭**：耗材问的是"整栋房子该换什么了"，之前只算当前家庭，B 家的滤芯
  归零而人停在 A 家时，侧栏圆点和挂件角标都不会动。现在两个家的耗材一起列，
  第二行写「家庭 · 房间」，分组排序也按家庭分开（两个家的「客厅」不再并成一组）。
  选设备的树改成家庭 → 房间 → 设备三层。侧栏的耗材入口挪到了分隔线下方。
- **圆环卡**：跨家庭后第二行变长会被截，属性名搬进圆环里、写在百分比下方，第二行只留位置，
  字号回到 11px；太长仍省略，鼠标停上去看全称。
- **桌面挂件单列居中**：只有一列时，多出来的宽度左右平分（之前全堆在右侧，
  右边留白明显比左边大）。
- **后台通知的图标**：以前换过程序图标后，系统通知里还会沿用第一次弹通知时的旧图标；
  现在每次启动重新登记一次，通知图标跟着换。
- **顶栏三颗胶囊统一**：「在线设备」前面那枚绿点换成了简笔画房子——绿点在这套界面里表示
  "开着 / 在线"，压在「6 台开启」前面容易被读成这一栏的状态。另外设置 → 外观里的样式
  预览改成沿胶囊自己那圈圆角描边，不再垫一块大一圈的色块。
- 轮询频率统一成两档（可见 3 秒 / 全部隐藏 15 秒），去掉挂件里一个从未生效的独立档位。

### 变更与移除

- **顶栏搜索框取消**（`Ctrl+F` 一并取消）。几十台设备的规模下它用得很少，位置让给了消息入口；
  现在按房间导航找设备。
- **详情页左下角现在是空的**。原来那里是「隐藏此设备」按钮（隐藏设备的操作一直都在卡片
  右键菜单里，没有丢）。之后在同一位置试过「单设备消息记录」和「设备事件最新一条」，
  前者只有 4 台会发通知的设备有内容、后者实测效果不理想，都撤掉了；与其放一块时有时无的
  内容，不如把位置留出来。

## 安装

1. 解压整个目录（不要只拷 exe，`_internal\` 和 `go2rtc\` 都要保留）。
2. 双击 `MiHomePanel.exe`。
3. 首次启动会弹出二维码，用米家 App 扫码登录；凭据只保存在本机。

从 0.1.8 升级可以直接覆盖程序目录，设置与登录态都在 `%LOCALAPPDATA%\MiHomePanel\`
下，不受影响。

系统要求：Windows 10 / 11 x64。

## 已知限制

- 消息中心只读、且只有**最近几条**：云端这个接口没有翻页游标（`limit` / `type` /
  `timestamp` 怎么传都不改变结果，实测只回 6 条），更早的记录、单台设备的历史和场景日志
  都要回米家 App 看。
- 设备事件（开锁记录、人体触发次数）不展示：云端接口只回答"最近一次发生在什么时候"，
  不是历史。
- 取消搜索后，按名字找设备只能靠房间导航和卡片顺序。
- 挂件只做了三档窗口、宫格槽位与设备管理；**折叠状态条、背景色 / 锁定、多屏夹回还没做**。
- 挂件的跨家庭能力只体现在「选设备」这一步：挂件本身不区分家庭，家庭切换不影响它
  （耗材页例外，它现在跨家庭统计）。
- 用别的工具强杀 `explorer.exe` 且系统没开自动重启 shell 时，桌面要手动拉起来；挂件会在
  shell 回来后自己贴回去，但期间桌面上看不到它。托盘图标的自动重试只覆盖启动阶段，
  运行期间 explorer 重启后需要重启一次程序。
- 目前同一时间只支持一个米家账号。
- 摄像头只做实时画面、声音和云台方向；画质切换、回放、云存储不在计划内。
- 耗材页只收数值型属性（百分比、剩余量这类）；枚举、布尔、文本属性没有"阈值"可套，
  不提供。
- 未适配的品类会走通用兜底，控件能出，但文案可能仍是云端英文。
- 全局快捷键**跨家庭也唯一**：家庭 A 和家庭 B 不能各用一个 `Ctrl+1`。
- "本程序启动时"只在**登录且设备列表加载成功**后触发；未登录时那条规则会等到下次启动。
- 图标用的是单纯的显示器 + 房子造型，与米家官方图标无关。
