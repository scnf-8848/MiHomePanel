# MiHomePanel v0.1.8

这个版本没有新功能。修的是三个**出了事也看不出来**的问题：托盘图标可能没挂上、而程序
以为挂上了；设置可能没存下来、而程序一声不吭；托盘不可用时关掉面板，会把桌面挂件一起
带走。现在这些情况能自己发现，必要时会明确告诉你。

解压后双击 `MiHomePanel.exe` 即可使用，压缩包仍自带打过补丁的 go2rtc（首帧约 2 秒）。

## 本次更新

### 修正

- **托盘图标不再"假装成功"**：以前调完系统接口就不再确认结果，所以 explorer 重启过、
  托盘区满了、或者被安全软件拦了一下，都会出现"图标没出来，而程序以为出来了"。现在
  启动后向系统反查图标是否真的在托盘里，没挂上会自动重试三次（约 1.2 / 3.5 / 9 秒），
  三次都不行就写进日志。
- **关闭面板的行为和设置里的选项对上了**：选「收进托盘」但托盘不可用时，不再顺手把整个
  程序退掉（桌面挂件会跟着消失），改为只隐藏主窗口，挂件照常工作。
- **设置存不住时会当面说**：以前保存失败是被静默吞掉的，表现就是"改完设置、重启就还原"
  "挂件里加的设备记不住"。现在启动时先试写一次数据目录，失败就弹一条提示，说明可能是
  磁盘满、目录只读或被安全软件的受控文件夹访问拦住，并指出日志在哪。
- **挂件右键菜单**：新增「打开主界面」和「退出程序」，托盘图标找不到时也有路可走。

### 新增

- 运行日志落到 `%LOCALAPPDATA%\MiHomePanel\logs\`（启动、托盘、设置各一份）。以后遇到
  "图标不出现""设置不保存"这类问题，先看这几个文件，不用再重开控制台版。

## 安装

1. 解压整个目录（不要只拷 exe，`_internal\` 和 `go2rtc\` 都要保留）。
2. 双击 `MiHomePanel.exe`。
3. 首次启动会弹出二维码，用米家 App 扫码登录；凭据只保存在本机。

从 0.1.7 升级可以直接覆盖程序目录，设置与登录态都在 `%LOCALAPPDATA%\MiHomePanel\`
下，不受影响。

系统要求：Windows 10 / 11 x64。

## 已知限制

- 挂件只做了三档窗口、宫格槽位与设备管理；**折叠状态条、背景色 / 锁定、多屏夹回还没做**。
- 挂件的跨家庭能力只体现在「选设备」这一步：挂件本身不区分家庭，家庭切换不影响它。
- 用别的工具强杀 `explorer.exe` 且系统没开自动重启 shell 时，桌面要手动拉起来；挂件会在
  shell 回来后自己贴回去，但期间桌面上看不到它。托盘图标的自动重试只覆盖启动阶段，
  运行期间 explorer 重启后需要重启一次程序。
- 目前同一时间只支持一个米家账号。
- 摄像头只做实时画面、声音和云台方向；画质切换、回放、云存储不在计划内。
- 耗材页只收数值型属性（百分比、剩余量这类）；枚举、布尔、文本属性没有"阈值"可套，
  不提供。
- 未适配的品类会走通用兜底，控件能出，但文案可能仍是云端英文。
- 全局快捷键**跨家庭也唯一**：家庭 A 和家庭 B 不能各用一个 `Ctrl+1`。
- "本程序启动时"只在**登录且设备列表加载成功**后触发；未登录时那条规则会等到下次启动。
- 图标用的是单纯的显示器 + 房子造型，与米家官方图标无关。
