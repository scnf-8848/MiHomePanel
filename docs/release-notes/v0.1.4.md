# MiHomePanel v0.1.4

一个收口版：把电脑自动化的快捷键规则整明白了，并让标题栏、任务栏、托盘终于用同一枚图标。
解压后双击 `MiHomePanel.exe` 即可使用，压缩包仍自带打过补丁的 go2rtc。

## 本次更新

- **图标三处一致了**：v0.1.3 加了图标，但标题栏和托盘还是代码画的旧样子、任务栏是新的
  ——同一个程序三个图标。现在三处都读同一张 `app.ico`。
- **一个快捷键只归一条规则**：以前两条规则可以设成同一个键，按下时**两条都会跑**；
  现在保存就拦住，并说明这个键被哪条规则占着。**停用的规则也算占着**——键是分配给
  一条规则的，不是"运行时谁先抢到算谁的"，这样"按了没反应"只有一个答案：那条规则关着。
- **从回收站还原的规则一律是停用的**：还原的是一条规则，不该顺带恢复它的运行。点开
  开关才算真正启用，那一刻如果键已经被别的程序占着，会当场提示。
- **还原时快捷键被别的新规则占了**：撞车的那几个键会被清掉，提示里写明是哪条规则占着，
  同一规则里**其余触发原样保留**——清的是冲突的那条，不是全部。
- **多快捷键的规则不会被一个坏键拖垮**：一条规则挂 `Ctrl+1` 和 `Ctrl+2`，只有 `Ctrl+1`
  被别的程序占着时，`Ctrl+2` 照常触发。列表卡片会标「热键没注册上」，鼠标悬停看具体原因。
- **新触发方式「本程序启动时」**：程序启动、设备列表就绪约两秒后自动触发一次，可以做
  "开机就把灯调成暖光"这类事。它在编辑页里不需要填快捷键，那格会写"程序启动、设备就绪后
  自动触发一次"。
- **编辑页能重录正在用的那个快捷键了**：以前规则启用时点进编辑页，想重输同一个组合，按键
  会被程序自己抢走（还能听到音箱播报）。现在打开编辑页会先临时退掉这条规则的热键，关掉
  自动恢复。
- **数字键按主键盘还是小键盘都算**：`Ctrl+1` 以前只认主键盘那个 `1`，按小键盘的 `1` 没反应。
- **编辑页那一格改成直说结论**：以前写「注册状态：未注册」，再配一句「保存后注册」或
  「规则已停用，启用后注册」。现在只有三种——绿色的「可以注册」、红色的
  「与「X」的快捷键冲突」、红色的「被其它程序占用，换个键」。能存是绿，存不进去是红，
  和规则启停无关。
- **允许没有触发方式的规则**：把触发行删光也能保存（它不会被任何事件唤起），卡片上写
  「未设置触发」。这种规则通常出现在"还原时键被占了"之后，进编辑页补一个就行。

## 安装

1. 解压整个目录（不要只拷 exe，`_internal\` 和 `go2rtc\` 都要保留）。
2. 双击 `MiHomePanel.exe`。
3. 首次启动会弹出二维码，用米家 App 扫码登录；凭据只保存在本机。

系统要求：Windows 10 / 11 x64。

## 已知限制

- 「耗材」「监控」两个入口仍是占位，页面还在规划。
- 目前同一时间只支持一个米家账号。
- 摄像头只做实时画面、声音和云台方向；画质切换、回放、云存储不在计划内。
- 未适配的品类会走通用兜底，控件能出，但文案可能仍是云端英文。
- 全局快捷键**跨家庭也唯一**：家庭 A 和家庭 B 不能各用一个 `Ctrl+1`。热键是操作系统级的，
  不分家庭。同理，把 `Ctrl+1` 从一条规则挪到另一条要改两次（先改掉或删掉原来那条）。
- "本程序启动时"只在**登录且设备列表加载成功**后触发；未登录时那条规则会等到下次启动。
- 图标用的是单纯的显示器 + 房子造型，与米家官方图标无关。
