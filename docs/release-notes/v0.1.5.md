# MiHomePanel v0.1.5

一个收口版：**功能与 v0.1.4 一致**，这次动的是文档、仓库和隐私边界——把公开文档里
残留的真实家庭名 / 房间名 / 设备标识换成示例占位，并补上一道提交前的自动审计；
另外删掉了「电脑自动化」页标题下那句已经对不上的总述。
解压后双击 `MiHomePanel.exe` 即可使用，压缩包仍自带打过补丁的 go2rtc。

## 本次更新

- **「电脑自动化」页头那句过时的总述删掉了**：标题下原来写着「每条规则 = 一个全局热键 →
  电脑条件 → 米家虚拟事件。停用后热键立即释放。」，这已经跟不上现在的规则——一条规则
  可以挂多个快捷键、也可以用「本程序启动时」触发，动作也不止发虚拟事件，留着只会让人
  以为功能比实际窄。删掉之后，标题下这行只在需要时出现：说明列表里只有当前这个家庭的
  规则；还有没归到家庭的旧规则时，提醒打开并保存后会归到当前家庭。没有可说的内容时
  整行隐藏，列表直接顶到标题下，不再空出一行。
- **公开文档里的标识全部改成示例**：门牌号式家庭名、房间名、设备 `did`、网关 IP、
  本机路径，统一改写为 `示例家庭`、`示例-客厅`、`1000000001`、`192.168.1.10`、
  `<用户名>` 这类占位；型号、品类、规格 urn 属于公开信息，照旧保留。口径写在
  `AGENTS.md` 里，避免各写各的。
- **仓库多了一道提交前审计**：`scripts/audit_privacy.py` 扫受版本控制的文件——凭据字段、
  Cookie、内网 IP、用户主目录路径、设备 `did`、手机号 / 邮箱、家庭号与截图；`--staged`
  模式用在提交前，能查任何一个历史提交。真实名字这类正则认不出来的，靠一份只在本地存在
  的词表兜底（词表本身不入库）。
- **README 加了「数据与隐私」声明**：说明文档中的家庭 / 房间 / 设备标识均为示例、
  米家 App 采集原件不入库、凭据只留在本机。

## 安装

1. 解压整个目录（不要只拷 exe，`_internal\` 和 `go2rtc\` 都要保留）。
2. 双击 `MiHomePanel.exe`。
3. 首次启动会弹出二维码，用米家 App 扫码登录；凭据只保存在本机。

系统要求：Windows 10 / 11 x64。

## 已知限制

- 「耗材」「监控」两个入口仍是占位，页面还在规划。
- 目前同一时间只支持一个米家账号。
- 摄像头只做实时画面、声音和云台方向；画质切换、回放、云存储不在计划内。
- 未适配的品类会走通用兜底，控件能出，但文案可能仍是云端英文。
- 全局快捷键**跨家庭也唯一**：家庭 A 和家庭 B 不能各用一个 `Ctrl+1`。热键是操作系统级的，
  不分家庭。同理，把 `Ctrl+1` 从一条规则挪到另一条要改两次（先改掉或删掉原来那条）。
- "本程序启动时"只在**登录且设备列表加载成功**后触发；未登录时那条规则会等到下次启动。
- 图标用的是单纯的显示器 + 房子造型，与米家官方图标无关。
