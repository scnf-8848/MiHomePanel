# MiHomePanel v0.1.3

一个外观版：新增 11 套渐变背景、给程序配了图标，并把背景预设重新命名分组。
解压后双击 `MiHomePanel.exe` 即可使用，安装包仍自带打过补丁的 go2rtc。

## 本次更新

- **有了自己的图标**：一块显示器，屏幕里一间房子——指"在电脑里的米家"。任务栏、
  桌面快捷方式、开始菜单、窗口标题栏都会显示；16 / 24 / 32 像素的小尺寸单独画过
  （只留房子和底座），不会糊成一团。
- **背景预设扩到 24 档**：7 档纯色 + 17 档渐变。渐变里新增的 11 套是从 CSS
  `linear-gradient` 收来的，色相弧保留、明度按本项目重算（浅色统一 L84、深色按
  右上 23 递减到左下 11），所以浅色下不会因为设计稿太暗而压不住正文。
- **渐变全部改用编号 1–17，并按颜色相近的顺序排列**：以前一半有名字一半是数字，
  「晨光 / 夜色 / 极光」和「1 / 2 / 3」两套指法互相打架，而其中本来就有几对颜色
  极接近，名字反而更容易指错。现在从橙 → 青 → 蓝 → 紫 → 粉绕一圈，相邻两套的
  色相最多只差 14 度，翻一遍就能找到想要的那端。
- **纯色档改成直白的名字**：暖沙 → 米黄、雾蓝 → 浅蓝、鼠尾草 → 浅绿、藕粉 →
  浅粉、薰衣草 → 浅紫、石板 → 灰蓝。
- **设置页里纯色和渐变分开摆**：两组色块之间加了一条细分隔线。
- **顶栏和内容之间那条线改成了一条"带"**：不再是 1px 硬线，而是一条带透明度的
  分隔带，明暗两档方向相反（浅色压深、深色提亮），背景的渐变色会从底下透出来。
- **右上搜索框、左侧边栏、场景按钮、快捷语音指令条、状态胶囊一起透**：以前只有
  卡片是半透明的，这些控件各自是一块实心白（深色下是实心黑），压在渐变背景上像
  贴了几张纸。现在它们和卡片是同一层"磨砂玻璃"；语音指令框那圈描边也一起透了，
  不再把半透明胶囊重新勾成一个贴纸。
- **大窗口下渐变背景的斜纹没了**：背景抖动的采样以前只处理 90 度整数倍的方向，
  换成别的角度后 8bit 量化台阶会连成一条条斜带。现在支持任意角度。
- **exe 属性里能看到版本号了**：以前 `MiHomePanel.exe` 右键「属性 → 详细信息」是空的
  （PyInstaller 默认不写 PE 版本资源），现在会显示对应版本；程序内标题和「关于」页
  一直是对的。

## 安装

1. 解压整个目录（不要只拷 exe，旁边的依赖目录和 `go2rtc/` 都要保留）。
2. 双击 `MiHomePanel.exe`。
3. 首次启动会弹出二维码，用米家 App 扫码登录；凭据只保存在本机。

系统要求：Windows 10 / 11 x64。

## 已知限制

- 「耗材」「监控」两个入口仍是占位，页面还在规划。
- 目前同一时间只支持一个米家账号。
- 摄像头只做实时画面、声音和云台方向；画质切换、回放、云存储不在计划内。
- 未适配的品类会走通用兜底，控件能出，但文案可能仍是云端英文。
- 图标用的是单纯的显示器 + 房子造型，与米家官方图标无关。
