# MiHomePanel v0.1.2

一个修复版：修掉 v0.1.1 里「强制刷新」点了没反应的缺陷，并把一次性提示的样式与状态
语义统一。解压后双击 `MiHomePanel.exe` 即可使用，安装包仍自带打过补丁的 go2rtc。

## 本次更新

- **修掉「强制刷新」点了没反应**：v0.1.1 里在设备右键菜单点「强制刷新」会抛
  `TypeError`（把 `DeviceSpec.properties` 当方法调用），界面上什么都不发生，也没有
  任何提示，看起来像按钮坏了。现在会先清掉这台设备「已确认不支持」的历史记录，再立刻
  重查它全部可读属性，并在说话条下方提示「已刷新 N 项属性」；一项都没读到会提示
  「设备暂时无响应，稍后会自动重试」。清掉多少条旧记录只写控制台日志，不上界面。
- **一次性提示改成窗口内浮层**（强制刷新、重置设备配置、说话条发送结果）：锚在说话条
  输入框下方、水平居中，固定 3 秒消失；不受鼠标移动 / 悬停 / 焦点影响，鼠标划过设备
  卡片也不会把它收掉。
- **提示状态收成成功 / 失败两档**：绿点是成功、红点是失败，不再有第三档"中性"。
  说话条「发送失败」现在显示红点（之前会和成功一样显示绿点）；无法识别的状态一律按
  失败处理，不会再被静默当成成功。
- **配色与顶部警告条对齐**：状态色按 9%（深色 16%）混进底色、1px 描边按 38%
  （深色 52%）混，状态色只用在左侧圆点上，文字仍是主文字色。
- **「转无线」的解释改成悬停提示**：以前要点一下才弹一条说明，现在鼠标停在那一路按键
  上就显示「已转无线：这一路常通电，要联动请在实体键上按」。点它仍然不发任何指令，
  避免误断给智能灯供电的那一路继电器。

## 安装

1. 解压整个目录（不要只拷 exe，旁边的依赖目录和 `go2rtc/` 都要保留）。
2. 双击 `MiHomePanel.exe`。
3. 首次启动会弹出二维码，用米家 App 扫码登录；凭据只保存在本机。

系统要求：Windows 10 / 11 x64。

## 已知限制

- 「耗材」「监控」两个入口仍是占位，页面还在规划。
- 目前同一时间只支持一个米家账号。
- 摄像头只做实时画面、声音和云台方向；画质切换、回放、云存储不在计划内。
- 未适配的品类会走通用兜底，控件能出，但文案可能仍是云端英文。
- `MiHomePanel.exe` 右键「属性 → 详细信息」里没有版本号；程序内标题与「关于」页是准确的。
