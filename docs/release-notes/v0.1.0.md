# MiHomePanel v0.1.0

第一个面向普通用户的 Windows 发布版。解压后双击 `MiHomePanel.exe` 即可使用，安装包已自带打过补丁的 go2rtc，不需要再单独配置取流组件。

## 本次更新

- **摄像头**：开播首帧实测 2.20–3.47 秒（官方取流约 4.8–6.3 秒），详情页和卡片都能直接播放；支持暂停、独立窗口、声音开关和云台方向盘。
- **在线状态**：设备清单会定期从云端刷新，掉线设备能及时显示；发指令后只回读目标设备，几秒内确认写入是否生效。
- **排序与隐藏**：设置页改成两个互斥 tab（「家庭 → 房间 → 设备」/「家庭 → 快捷场景」），拖动排序、开关隐藏；顺序按云端家庭/房间 ID 保存，改名不会失效。
- **电脑自动化**：一条规则可配多个触发，任一命中即执行；发虚拟事件时可以选择当前家庭的中枢网关；新增回收站和可按关键字、规则、结果、时间筛选的触发日志。
- **设置新增「关于」页**：显示版本号、GPL-3.0-or-later、源码与反馈地址、go2rtc 等第三方组件说明；窗口标题也会显示 `v0.1.0`。
- **文档**：README 功能列表重新整理，第一次接触项目可以快速知道能做什么；实现细节和边界情况移到开发文档。

## 安装

1. 解压整个目录（不要只拷 exe，旁边的依赖目录和 `go2rtc/` 都要保留）。
2. 双击 `MiHomePanel.exe`。
3. 首次启动会弹出二维码，用米家 App 扫码登录；凭据只保存在本机。

系统要求：Windows 10 / 11 x64。

## 已知限制

- 「耗材」「监控」两个入口仍是占位，页面还在规划。
- 目前同一时间只支持一个米家账号。
- 摄像头只做实时画面、声音和云台方向；画质切换、回放、云存储不在计划内。
- 未适配的品类会走通用兜底，控件能出，但文案可能仍是云端英文。
